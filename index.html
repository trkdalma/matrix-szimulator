Mátrix Sétálója

A robot egy 5×5-ös sziget közepén, a (3, 3) mezőn áll. Minden lépésnél 25-25% eséllyel megy fel, le, jobbra vagy balra. Lemegy-e a vízbe 4 lépésen belül?

Szimuláció Számold ki!

    A ciklus addig fut, amíg a fenti feltétel igaz. Leesésnél az x vagy az y kilép az 1–5 tartományból.

    Utolsó futások

      ✕ a szám a lépés, amelyben leesett. ✓ a robot mind a 4 lépést túlélte.

      Hogyan áll be az érték?

      Útkereső

      A robot 4 lépést tesz, és minden lépés egyforma eséllyel Fel, Le, Jobbra vagy Balra. Rakd össze a 4 lépést. Ha az út leesésbe vezet, bekerül a listába. Ha a robot már a 3. lépésben leesik, a 4. lépést akkor is add meg: az külön útnak számít.

      Ha már van 4 lépés, a következő nyíl új utat kezd.

      Megtalált utak

      Számold ki!

      Mekkora az esélye, hogy a robot 4 lépésből leesik? Oldd meg lépésenként. A következő kérdés akkor nyílik meg, ha az előzőt megoldottad.

        Vissza a szimulációhoz
        Bónusz: ugyanez programmal

        Négy egymásba ágyazott ciklus végigmegy mind a 256 úton, és megszámolja a leeséseket.

        int kedvezo = 0;
for (int a = 1; a <= 4; a++)
 for (int b = 1; b <= 4; b++)
  for (int c = 1; c <= 4; c++)
   for (int d = 1; d <= 4; d++)
   {
     int[] lepesek = { a, b, c, d };
     int x = 3, y = 3, n = 0;
     while (x > 0 && x < 6 && y > 0 && y < 6 && n < 4)
     {
       int irany = lepesek[n];
       if (irany == 1) y++;
       else if (irany == 2) y--;
       else if (irany == 3) x++;
       else x--;
       n++;
     }
     if (x < 1 || x > 5 || y < 1 || y > 5) kedvezo++;
   }
Console.WriteLine($"{kedvezo} / 256");
